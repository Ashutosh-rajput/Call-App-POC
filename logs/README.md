# Call Streaming Diagnostic & Debug Logs

This directory contains real-time and captured logs for the AOSP Call Streaming Test App:

## Log Files
- **`call_streaming_debug.log`**: Contains the full lifecycle logs generated by `CallStreamingServiceControl`, `TelecomHelper`, `AudioProbeManager`, and `NetworkTransportProbe`.
- **`call_streaming_live.log`**: Real-time logcat capture filtered by the app's Telecom, Audio, and Streaming tags.

## Scripts to Capture Logs into this Directory

### 1. Pull Device Log File
Extracts the on-device log file directly to `logs/call_streaming_debug.log`:
- **Windows**: `..\scripts\pull_device_logs.bat`
- **POSIX**: `../scripts/pull_device_logs.sh`

### 2. Stream Live Logcat to File
Streams live logcat directly into `logs/call_streaming_live.log`:
- **Windows**: `..\scripts\stream_live_logcat.bat`
- **POSIX**: `../scripts/stream_live_logcat.sh`
